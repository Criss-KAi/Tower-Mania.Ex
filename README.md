# Tower-Mania

**Tower-Mania** es un videojuego de plataformas 2D en pixel art, desarrollado con Unity 6, creado para fortalecer el pensamiento algorítmico. A lo largo de la zona tutorial, la zona industrial y la Torre, el jugador resuelve puzzles que exigen ordenar secuencias de pasos, planificar con recursos limitados, optimizar movimientos y comprobar su solución, mientras controla a Minerva, Hugo o Idalia y se enfrenta a enemigos y jefes.

## Cómo instalarlo y jugar

1. Entra al repositorio: **[Tower-Mania.Ex](https://github.com/Criss-KAi/Tower-Mania.Ex)**.
2. Haz clic en el botón verde **Code** y luego en **Download ZIP**.
3. Cuando termine la descarga, **extrae el .zip** en una carpeta (clic derecho → *Extraer todo*). No ejecutes el juego desde dentro del .zip.
4. Dentro de lo extraído, abre la carpeta **`Tower-mania game`**.
5. Ejecuta **`Tower-Mania.exe`**.

No necesita instalación: basta con extraer y abrir.
### Si Windows muestra un aviso de seguridad

Como el juego no está firmado, Windows puede mostrar "Windows protegió su PC".
Haz clic en **Más información** y luego en **Ejecutar de todas formas**.

## Requisitos

- Windows 10 u 11 de 64 bits
- Espacio en disco: 256 MB
- Teclado y ratón

## Controles

| Acción | Control |
|---|---|
| Moverse | A y D |
| Saltar | W |
| Atacar | Espacio |
| Segundo ataque | Clic izquierdo o derecho del ratón |
| Dash | Shift |
| Resonancia | R |
| Curarse | G |
| Interactuar | F |
| Inventario | Tab |
| Pausa | Escape |

Durante el juego, la Divinidad te explicará las mecánicas.
